# Scannable JEI Compat

A JEI compatibility addon for [Scannable](https://www.curseforge.com/minecraft/mc-mods/scannable).  
It lets you configure Scannable's configurable scanner modules by dragging ingredients directly from JEI into the module configuration GUI.

## Features

- **Block Scanner Module**  
  Drag a block item from JEI into one of the 5 slots in the Configurable Block Scanner Module GUI to add/set that block.

- **Entity Scanner Module**  
  Drag a spawn egg from JEI into one of the 5 slots in the Configurable Entity Scanner Module GUI to add/set that entity type.

## Requirements

- Minecraft: 1.20.1
- Forge: 47.3.29+
- JEI
- Scannable
- Architectury API (required by Scannable)

## Installation

1. Download a release jar.
2. Place the jar into your Minecraft instance's `mods` folder.
3. Make sure JEI, Scannable, and Architectury API are also installed.
4. Launch the game, open a Configurable Block/Entity Scanner Module, and drag ingredients from JEI into the slots.
